Mail dashboard

Privacy policy

Effective 19 October 2026

Mail dashboard is a personal tool used only by Prajjwal Lekhi, with Gmail accounts that belong to him. This page explains what it does with data from those accounts.

What it accesses

  • Read Gmail (gmail.readonly): the messages in each connected inbox from the last seven days, to show them on one screen.
  • Send email (gmail.send): only replies that Prajjwal writes and sends himself from the dashboard.

It does not delete, archive, label or forward email, and it does not change any account settings.

Where the data goes

  • Messages are read on Prajjwal's own computer. A list of threads and their scores is stored there. Message text is kept only until a thread has been scored, then removed.
  • To sort threads by importance, the text of recent messages in each thread is sent to the Jev API run by TypeSafe AI, which returns a score. Nothing else receives email content.
  • Sign-in tokens are stored on the same computer in files only his user account can read.

No data is sold, shared for advertising, or used to train AI models by this tool.

Google API Services User Data Policy

Mail dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access for any account can be removed at any time at myaccount.google.com/permissions. Deleting the tool's folder on the computer removes everything it stored.
